安装包（推荐）

  • EukaryLauncher-0.2.0-Setup.exe —— 双击安装即可
  • 自包含单文件，不需要预先安装 .NET 运行时
  • 按用户安装到 %LOCALAPPDATA%\Programs\Eukary Launcher，不需要管理员权限
  • 卸载从开始菜单或「应用和功能」，已下载的游戏文件和 Java 运行时可选择保留

便携版

  • EukaryLauncher-v0.2.0-win-x64.zip —— 解压即用，不写注册表，适合免安装场景
系统要求：Windows 10 1607 及以上、64 位。Java 由启动器按需自动下载，无需手动安装。

其他下载方式

从源码构建

需要 Windows 10+ 与 .NET 8 SDK：

git clone https://github.com/EukaryDeveloper/Eukary-Launcher.git
cd Eukary-Launcher
dotnet publish EukaryLauncher.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true

构建与运行的更多细节见开发页面。

下载源说明

启动器下载游戏文件时默认使用国内镜像 BMCLAPI，失败自动回退 Mojang 官方源；镜像可在设置页切换。启动器不打包、不分发任何 Minecraft 游戏文件，所有游戏内容在用户本地运行时从官方源或镜像下载。
